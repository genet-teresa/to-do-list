# To-Do List App

This is a simple to-do list web app that I created using HTML, CSS, and JavaScript.  
I built this project to practice how websites actually work and how users can interact with them.

## What you can do

- Add new tasks
- Mark tasks as completed
- Edit tasks if needed
- Delete tasks
- See how many tasks are active, completed, and total

## How it works

The app uses JavaScript to store tasks in a list (array).  
Every time you add, edit, or delete a task, the page updates automatically without refreshing.

## What I learned

While building this project, I learned:

- How HTML, CSS, and JavaScript work together
- How to use DOM manipulation to update the page
- How to respond to user actions like clicks and typing
- How to organize code into functions

## Project files

- `index.html` → the structure of the app  
- `style.css` → the design and layout  
- `script.js` → the logic behind the app  

## Final thoughts

This is one of my beginner projects, but it helped me understand how interactive web apps are built.  
In the future, I would like to improve it by adding features like saving tasks or better design.
